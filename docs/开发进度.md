### 补充说明

- **T03 验收证据**：列表与详情均接入真实接口 `/api/news`、`/api/news/{id}`、`/api/announcements`，
  Network 面板确认请求路径无重复 `/api` 前缀；不存在的 ID 走「内容不存在」态而非白屏；
  详情页连续切换到不同 ID 会重新请求（监听路由参数）。
- **T04 验收证据**：项目列表、详情与学习资料列表均返回 200 真实数据（项目 3 条、资料 13 条）；
  四种状态（loading / error+重试 / empty / normal）齐全；外链仅放行 `http`/`https`，
  无链接时显示文字而非留一个点了没反应的假按钮。
- **T05 验收证据**：首页轮播接通 `/api/banner`、关于我们接通 `/api/lab/info` 与 `/api/lab/team`；
  竞赛组队接通 `/api/platform/forum` 与详情接口；实验室简介 `labDesc` 为 HTML，已用 `v-html` 渲染；
  缺失头像与缺失联系方式（null）均用 `v-if` 收口，无裂图、无死链。
- **本期明确不做**：在线投递（`/join`）、全站搜索（`/search`）、成长路线（`/growth`）
  ——三者所依赖的 POST / 检索接口未提供，页面统一做成说明卡，不含假数据、不含无效按钮。
- **联调前提**：以上均依赖 `vite.config.js` 中 `API_TARGET` 指向的后端地址，
  负责人下发本地后端后，只需修改该常量的值即可切换。
